# BLACK EAGLE Travel & Tourism

تم استكمال الموقع والصفحات الداخلية ونظام المحاسبة المحلي مع الحفاظ على الهوية والتنسيق الأساسيين.

## الصفحات
- الرئيسية
- الوجهات
- الرحلات
- الفنادق
- التأشيرات
- الحجوزات
- تواصل معنا

## المحاسبة
- لوحة التحكم
- الحجوزات
- العملاء والموردون
- الفواتير والمدفوعات
- المصروفات
- دفتر اليومية ودليل الحسابات
- التقارير والإعدادات

البيانات الحالية محلية عبر localStorage، ويمكن ربطها بـ Firebase لاحقًا.
